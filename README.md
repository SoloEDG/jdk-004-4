# VOID SIGNAL · 虚空信号

## 安装

Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8084 。可通过 PORT 环境变量修改端口。

## 场地编辑 / 可破坏掩体

- 右侧「场地编辑」选择形状后，点击画布落点；开启「开始编辑」时画布只用于放置，退出后恢复指针射击。
- 青色**可破坏掩体**会被武器打碎，紫色**导航障碍**永久改变敌人绕行路线。两者同时阻挡玩家、敌人与弹幕。
- 悬停预览是纯计算：同一份预览会参与战斗碰撞与波次出生检查，暂停时不会移动任何战斗实体。
- 若放置会把角色围死或大幅切断可行走区域，会拒绝应用并保留原场地。
- 导航只在开局全量构建一次，之后每次放置或掩体碎裂只局部更新受影响格；敌人绕过遮挡物时复用缓存路径。
- 掩体碎裂会在同一模拟步内同步开放通行格并刷新遮挡集合，掉落的晶体只会落在角色可达的格子上。
